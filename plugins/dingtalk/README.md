# 钉钉机器人与工作台

企业机器人通过钉钉 Stream 网关接收消息，无需公开回调端口；使用 Node 内建 WebSocket、fetch、crypto，无兄弟插件依赖。自定义群机器人 Webhook 单独支持文字和 Markdown 通知。

## 配置

1. 在钉钉开放平台创建企业内部应用，启用机器人与 Stream 模式，取得 AppKey、AppSecret、robotCode。
2. 配置机器人相关消息、下载、上传及发送权限；在插件面板填写凭据和机器人编码，启用双向会话。密钥通过宿主 secrets 存储。
3. 可配置 Staff ID 白名单、默认工作目录、模型和思考强度。设置白名单后，缺少发送者身份或不在名单的消息均拒绝。
4. 自定义群通知填写 Webhook URL 和可选签名密钥。自定义 Webhook 与企业机器人媒体接口的权限不同。

## 命令

| 命令                                                          | 行为                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------- |
| `/help`                                                       | 查看命令和媒体限制                                    |
| `/new`、`/clear`、`/reset [prompt]`                           | 更换隔离账号；可选 prompt 立即在新上下文执行          |
| `/status`                                                     | 当前真实会话、运行 ID、模型、思考强度、目录和最近错误 |
| `/stop`、`/abort`                                             | 优先按稳定 runId 调用宿主 `abortRun`；失败明确反馈    |
| `/model [provider/id\|default]`                               | 查询或设置当前渠道会话的模型偏好                      |
| `/thinking [off\|minimal\|low\|medium\|high\|xhigh\|default]` | 查询或设置思考强度                                    |
| `/cwd [绝对路径\|default]`                                    | 查询或设置工作目录；目录必须存在，切换后启用新上下文  |

`/workspace` 是 `/cwd` 的兼容别名。未知命令只回复帮助提示，不会投递模型。命令名兼容大小写、全角字母与全角斜杠；`DEFAULT` 和思考强度兼容大小写。三个重置别名都接受可选 prompt，保留其字面内容，`/new /stop` 会把 `/stop` 作为模型输入。模型、思考强度和目录设置均轮换隔离账号并开启新上下文，旧在途操作失效；目录验证迟到不会覆盖之后的重置。普通消息在当前运行结束前会提示等待，不会覆盖待回信的运行。`/stop` 不排在媒体下载或 chat 投递之后：立即确认停止请求；媒体准备完成后不再投递，若宿主回执尚未返回，则收到回执后按 runId 中止。下载本身仍可能继续至完成或 30 秒超时。模型和目录最终可用性由宿主在下一次投递时验证，插件不会宣称已经切换成功。

会话按机器人账号、企业、群/单聊、渠道、线程和发送者隔离，并持久化 scope 的隔离账号与重置代次。新版宿主返回的稳定 `sessionId` 用于保存回信路由；网页主动续聊的无 runId `run_start` 可按该路由建立本轮回信，最终回到原目的地。旧宿主仅支持精确 `clientId + conversationId` 的内存兼容，不认领裸 `c1`。未知 runId 绝不借 sessionId 认领；回执前的事件只按回执精确 runId 重放。每轮结束仅回一次，采用最后一个助手正文候选，空正文或工具调用会清空前言候选，不拼接工具执行前言。无精确 runId 的网页任务只能在网页停止，插件明确反馈，绝不猜测 conversationId 中止。

## 媒体接收

支持 `picture`/`image`、富文本图片、`audio`/`voice`、`file`、`video` 回调。通过消息中的 `downloadCode`/`pictureDownloadCode` 调用企业机器人下载 API，下载实际内容：

- PNG/JPEG/GIF/WebP 图片以 `host.chat({text, attachments:[{path:"", imageData, mimeType, name}]})` 输入，绝不以下载 URL 代替图片。
- 文件、语音、视频以 `{path:"", fileData, mimeType, name}` 附件输入，由宿主持久化。当前使用通用二进制 MIME，保留回调文件名。
- 入站每个媒体（图片、文件、语音、视频）最大 10MiB，每条最多 8 张图片，媒体总计最大 20MiB，每条最多 16 个富文本片段。下载具备大小限制及超时。
- 语音、视频保留原文件；本插件不提供语音识别、视频抽帧或音视频解码。接收时明确告知，实际理解依赖模型可用工具。图片执行格式签名检查，不是完整像素解码；损坏但签名正确的图片仍可能由宿主/模型报错。
- 不支持的位置、卡片等类型、缺少下载码、认证失败、无权限、下载失败和格式检查失败都会反馈。没有 sessionWebhook 时拒绝投递，并记录状态错误。

需要支持 `host.chat.attachments` 的新版宿主。图片理解还依赖可用的视觉模型或宿主视觉桥。插件不提供旧宿主的 URL 文本降级。

## 媒体发送

AI 工具 `dingtalk` 支持 `action:"media"`；UI 消息接口也接受 `type:"send_media", payload:{...}`。当前面板没有独立媒体上传表单。指定本地 `path`、`mediaType` 和唯一接收目标 `openConversationId`（群）或 `userId`（员工单聊）：

| mediaType | 输入与边界                                           |
| --------- | ---------------------------------------------------- |
| `image`   | PNG/JPEG/GIF/WebP，本地文件上传后发送原生图片        |
| `audio`   | AMR 文件及 `duration` 秒；其他格式需转换或按文件发送 |
| `file`    | 本地文件，保留文件名与扩展名                         |
| `video`   | MP4、`duration` 秒及 `coverPath` 图片封面            |

每个上传文件不超过 20MiB；钉钉实际格式、大小、时长和权限限制可能更严格，平台错误会直接反馈。通过上传 API 获取 media_id，再调用企业机器人群消息或单聊发送 API；自定义/session Webhook 不支持任意二进制媒体发送。模型产生的附件不会自动转发，需显式调用媒体工具并指定收件目标。

所有 Webhook 与媒体请求校验 HTTP 状态及平台错误码；回信失败记录在 `/status` 的最近错误。Webhook 已失效或网络断开时无法保证错误本身还能送达原会话。

`/new`、`/clear` 与 `/reset` 立即更换隔离账号并保留模型、思考强度和目录偏好；下载或宿主投递尚未返回时也可重置。旧下载、延迟回执和任务事件不会重新绑定新会话，已知旧任务会请求中止；中止失败会明确提示。插件不排队入站消息，新会话可以立即接收下一条消息。

Stream 断开后重连；stop/reload 保留持久 scope、偏好、代次和稳定 sessionId 路由，不重置上下文，也不恢复未完成任务。reset、模型/目录设置与机器人账号变更撤销旧路由，重载不会复活旧代次。消息去重和旧宿主 owner 路由仅保存在内存。回信优先走原 sessionWebhook；失败时仅当原回调包含明确群/单聊类型和精确收件目标，才复用企业机器人发送接口回原目的地；缺少目标、权限或平台拒绝均记录真实错误，不改投配置群 Webhook。当前没有真实钉钉凭据联调证据，自动测试覆盖网关消息、HTTP 请求、附件、持久路由与宿主事件契约，仍需在企业环境验证权限、媒体模板和时长字段。
